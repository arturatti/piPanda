# piPanda — детская игра для Android (обучение чтению по слогам)

## 0. Имя и идентификация

- **Имя продукта:** piPanda (отображается пользователю)
- **Маскот:** панда
- **Технический id:** `com.syllables.syllables_apk` (не переименовываем — внутренний)
- **Разделение работ код/контент:** [CONTENT_HANDOFF.md](CONTENT_HANDOFF.md)

## 1. Цели и аудитория

**Аудитория:** дети 4-7 лет, осваивающие чтение по слогам.

**Цели:**
- Помочь ребёнку освоить слоговое чтение через игру
- Развивать мелкую моторику (drag&drop)
- Развивать память и внимание
- Никакой фрустрации: ошибка — не наказание, а подсказка

**Принципы:**
- Крупные элементы, простой UX (ребёнок 4 лет должен справиться)
- Никаких таймеров и штрафов в основном цикле
- Дружелюбные цвета, мягкие звуки, тёплый голос
- Прогресс — поощрение, не давление

---

## 2. Игровой цикл (раунд)

1. Случайным образом выбирается слово из словаря (с учётом текущего режима)
2. Открывается экран игры:
   - Сверху: картинка (если режим её показывает) + слово целиком (если режим показывает)
   - В центре: пустые ячейки по числу слогов (например, "Ворона" → 3 ячейки)
   - Снизу: 10 слогов (3 правильных + 7 случайных из пула слогов всего словаря), вперемешку
3. Ребёнок тянет слог из нижнего поля в ячейку
4. **При начале drag** слог озвучивается
5. **При drop в ячейку:**
   - Правильный → слог фиксируется, лёгкий звук подтверждения
   - Неправильный (попытки 1-2) → слог отскакивает обратно, без штрафа
   - Неправильный (попытка 3+) → слог отскакивает + слот мигает + озвучивается правильный слог как подсказка
6. Когда все ячейки заполнены правильно:
   - Анимация поздравления (конфетти/звёздочки)
   - Слово озвучивается целиком
   - Через 2-3 секунды — следующее слово

---

## 3. Режимы сложности

| № | Название | Картинка | Слово целиком | Озвучка слога при drag | Лишние слоги |
|---|---|---|---|---|---|
| 1 | Малыш | да | да | да | 3 |
| 2 | Базовый | да | да | да | 7 |
| 3 | Без картинки | нет | да | да | 7 |
| 4 | На слух | нет | нет (только озвучка слова целиком при старте раунда + по тапу на иконку «🔊») | да | 7 |
| 5 | Хардкор | нет | нет | нет | 7 |

В режиме "На слух" пользователь может нажать на иконку звука сколько угодно раз, чтобы переслушать слово.

## 4. Экраны

### 4.1. Главный экран (Home)
- Логотип/название
- Большая кнопка "Играть" → переход к выбору режима
- Кнопка "Прогресс" → экран статистики
- Кнопка "Настройки" (шестерёнка)

### 4.2. Выбор режима (ModeSelect)
- 5 крупных карточек с режимами
- Иконка + название + краткое описание ("С картинкой и словом")
- Тап → переход в игру

### 4.3. Игровой экран (Game)
- Верхняя зона: картинка + слово (по режиму) + кнопка «🔊 переслушать» (для режима 4)
- Центральная зона: ячейки для слогов
- Нижняя зона: 10 draggable-карточек со слогами
- Угол: кнопка "Назад", счётчик слов в текущей сессии
- Pull-to-refresh или кнопка "Другое слово" для пропуска

### 4.4. Статистика для родителя (Stats)
- Сколько слов пройдено всего
- Сколько раз играли (сессий)
- Список слов с разбивкой:
  - Слово / сколько раз играл / средняя точность (% попаданий с первой попытки)
- Слова, которые даются хуже всего (топ-5)
- Кнопка «Сбросить прогресс» (с подтверждением)

### 4.5. Настройки (Settings)
- Громкость (общая)
- Голос озвучки (если будет несколько)
- Звуковые эффекты вкл/выкл
- Анимации вкл/выкл (для слабых устройств)

---

## 5. Прогресс и сохранение

**Что сохраняем:**
- Список пройденных слов с количеством раундов на каждое
- Количество попыток на каждый слог (для статистики "что даётся хуже")
- Звёздочки за раунд:
  - 3 звезды — собрал с первой попытки на каждом слоге
  - 2 звезды — были ошибки, но не понадобилась подсказка
  - 1 звезда — была подсказка
- Общая статистика сессий

**Где храним:**
- `shared_preferences` для простых счётчиков
- Локальный JSON-файл (`progress.json`) для детальной статистики
- Сохранение при каждом завершённом раунде

## 6. Структура данных

### 6.1. Словарь слов (`assets/data/words.txt`)

Формат: `Слово|Сло-ги|имя_картинки.png`

```
Ворона|Во-ро-на|vorona.png
Малина|Ма-ли-на|malina.png
```

Слогораздел проставлен вручную (русский слогораздел не подчиняется простому алгоритму).

### 6.2. Пул слогов

Генерируется в рантайме из всего словаря. Все уникальные слоги собираются в один пул, из которого берутся "лишние" слоги для раунда (исключая правильные).

### 6.3. Картинки слов
- Путь: `assets/images/words/<имя>.png`
- Формат: PNG, 512×512, прозрачный фон, единый стиль (см. `image_prompt.md`)

### 6.4. Аудио слогов
- Путь: `assets/audio/syllables/<слог_транслит>.mp3`
- Например: `ma.mp3`, `ro.mp3`, `vo.mp3`
- Имена файлов — латиницей, в нижнем регистре, через дефис только если слог из 3+ символов: `aap.mp3` для "Ап".

### 6.5. Аудио слов целиком (для режима 4)
- Путь: `assets/audio/words/<имя>.mp3`
- Имена соответствуют ключам в словаре

## 8. Озвучка слогов и слов

**Решение по записи откладывается** — зависит от качества доступных вариантов. Перед началом реализации нужно сравнить:

1. **Android TTS** (Google TTS) — встроенный, бесплатный. Проверить актуальное качество русского голоса в 2026 (он сильно вырос за последние годы).
2. **Yandex SpeechKit** — платный, но русский голос топовый. Можно сгенерить один раз все слоги/слова и положить в assets как mp3 (тогда платим только за генерацию ~150-200 файлов).
3. **ElevenLabs / OpenAI TTS** — премиум-качество, английский лучше русского, но русский тоже годный. Аналогично — генерим оффлайн, кладём в assets.
4. **Live recording** — попросить кого-то с приятным голосом записать. Идеально для детей, но трудозатратно.

**Рекомендация:** прогенерить все 150-200 файлов один раз через один из AI-сервисов и положить в `assets/audio/`. Никакого рантайм-TTS — это даёт стабильное качество и работает оффлайн.

**Что нужно записать/сгенерить:**
- Все уникальные слоги из словаря (~80-100 файлов в `assets/audio/syllables/`)
- Все слова целиком (35 файлов в `assets/audio/words/`)
- Звуки UI: success.mp3, drop_correct.mp3, drop_wrong.mp3, hint.mp3 (~5-10 файлов)
- Опционально: фразы поощрения "молодец", "получилось" (3-5 файлов)

Конкретный сервис выбираем перед этапом озвучки в план-моде.

## 9. UX/UI принципы

- **Размеры:** все интерактивные элементы ≥ 64×64dp (детские пальцы)
- **Цвета:** тёплая палитра, без агрессивных красных. Ошибка — мягкий оранжевый или жёлтый.
- **Шрифт:** крупный, без засечек, высокая читаемость для дошкольников. Например, **Comfortaa** или **Nunito**, либо специальный детский шрифт типа **Andika**.
- **Слоги в карточках:** ВЕРХНИЙ РЕГИСТР, как на референсной картинке (ВО, РО, НА).
- **Картинки:** всегда верх экрана, чтобы не перекрывались пальцами при drag.
- **Анимации:** мягкие, без резких движений. Карточки "подпрыгивают" при появлении.
- **Звук всегда сопровождает действие:** drag — озвучка слога, drop — звук, победа — фанфары + слово целиком.

## 10. План реализации (этапы)

Финальный план будет в plan-mode перед стартом разработки. Предварительная разбивка:

### Этап 0 — подготовка контента
- Расширить словарь до финального формата (`Слово|Сло-ги|картинка.png`)
- Сгенерить картинки через Antigravity по `image_prompt.md`
- Выбрать сервис озвучки и сгенерить все аудиофайлы
- Подобрать UI-звуки

### Этап 1 — каркас Flutter
- `flutter create`, базовая структура папок
- Парсер `words.txt` → модели `Word`, `Syllable`
- Генератор пула слогов
- Главный экран → выбор режима → пустой игровой экран

### Этап 2 — игровой экран (режим Базовый)
- Layout: картинка/слово/ячейки/draggable слоги
- Drag&drop логика
- Озвучка слога при drag (audio_service)
- Логика проверки правильности
- Подсказка после 3-х ошибок
- Анимация победы + переход к следующему слову

### Этап 3 — остальные режимы
- Малыш (3 лишних слога)
- Без картинки
- На слух (озвучка слова + кнопка переслушать)
- Хардкор

### Этап 4 — прогресс и статистика
- Сохранение результатов в JSON
- Звёзды за раунд
- Экран статистики для родителя

### Этап 5 — настройки и полировка
- Экран настроек (громкость, голос, эффекты)
- Финальная полировка анимаций
- Тестирование на реальных детях

### Этап 6 — сборка
- Иконка приложения, splash-screen
- Подпись apk, сборка release
- Опционально: публикация в Google Play

## 11. Решённые вопросы (зафиксировано)

| Вопрос | Решение |
|---|---|
| Стек | Flutter |
| Управление | Drag&drop |
| Картинки | AI-генерация (Antigravity) по единому промпту |
| Озвучка | AI-генерация всех файлов оффлайн, в assets |
| Лишние слоги | Из пула слогов всего словаря (естественные) |
| Деление на слоги | Вручную в `words.txt` |
| Режимы | 5 режимов (см. п.3) |
| Прогресс | Сохраняем: пройденные слова, попытки, звёзды, статистика для родителя |
| Ошибка | 1-2 попытки — мягкий отскок, 3+ — отскок + подсказка озвучкой |
| Награда | Анимация (конфетти) + озвучка слова + автопереход 2-3с |
| MVP scope | Все 5 режимов сразу (определяем в plan-mode) |
