# 🐼 piPanda

**Учимся читать по слогам — играя**

## Что это

piPanda — образовательное приложение для детей 4–7 лет. Цель — помочь ребёнку перейти от букв к слогам, а от слогов — к чтению целых слов. Без штрафов, таймеров, рекламы. Только тёплая палитра, добрая панда-маскот и понятная механика.

## Что внутри

### 📚 Три тематических набора слов

| Набор | Что внутри | Слов |
|---|---|---|
| 🌈 **Стандартный** | Знакомые бытовые слова: мама, аптека, ракета, корова, малина… | 35 |
| 🦖 **Динозавры** | Тираннозавр, стегозавр, бронтозавр, диплодок, птеродактиль… | 15 |
| 🐲 **Рептилии** | Дракон, крокодил, игуана, ящерица, черепаха, лягушка | 6 |

### 🎮 Четыре режима сложности

- **🔆 Базовый** — картинка + слово + слоги
- **🔵 Без картинки** — только слово, надо опираться на чтение
- **💗 На слух** — нет картинки, нет слова, только озвучка
- **🟣 По картинке** — есть картинка, слова не видно — узнать по виду

### 🎯 Игровой процесс

- Все слова и слоги озвучены живым голосом
- Подсветка и анимация: текущий слог в слове светится, заполненные становятся зелёными
- **5-бальная система звёзд**: 5⭐ без ошибок, 4⭐ с одной, ниже — больше ошибок. Подсказка снижает потолок до 3⭐
- Опция «Подсказки»: после 3 ошибок диктор произносит правильный слог + подсвечивается нужная карточка
- Анимированный маскот-панда: на главной — читает книгу, переворачивает страницы; в игре — иногда выглядывает с края экрана

### 📊 Дашборд для родителей

На экране «Прогресс» — детальная картина того, как ребёнок развивается:

- **Сегодня vs Вчера** — раундов и средние звёзды с дельтой
- **Серия дней подряд** + всего раундов
- **Активность** по дням недели и часам суток
- **Линия средних звёзд** за последние 14 дней
- **Освоение слов** — три группы: знает уверенно / учится / нужно повторить
- **По темам** — раскрывающийся список со всеми словами (✅ зелёные пройденные / ⚪ серые ещё нет)
- **Распределение звёзд** — гистограмма
- **Личные рекорды** — лучшая серия 5⭐, раундов за день, самый быстрый 5⭐

### 🛠 Удобства

- Поддержка планшетов и телефонов, портрет и ландшафт
- Фоновая музыка с паузой при сворачивании
- Настройка количества слогов в задаче (6/8/10)
- Без рекламы, без покупок, без сбора данных
