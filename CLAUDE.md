# piPanda — детская игра для обучения слоговому чтению

## О проекте

Android-приложение для детей 4-7 лет: ребёнок собирает слова из слогов (drag&drop) с озвучкой и картинками. Полная проектная документация — [.info/PROJECT.md](.info/PROJECT.md). Разделение работ между кодом и контентом — [.info/CONTENT_HANDOFF.md](.info/CONTENT_HANDOFF.md).

**Название приложения:** piPanda (отображается пользователю)
**Внутреннее имя пакета:** `syllables_apk` / `com.syllables.syllables_apk` (не меняем — это технический id)

## Стек

- **Flutter** + Dart, целевая платформа Android
- **Хранение:** локально (`shared_preferences` + JSON для прогресса)
- **Аудио:** предзаписанные mp3 в `assets/audio/`, без рантайм-TTS
- **Состояние:** Riverpod (предварительно — финальный выбор в plan-mode)

## Ключевые решения (зафиксированы — не пересматривать без причины)

- **Слогораздел** проставлен вручную в `.info/words.txt`, формат `Слово|Сло-ги|картинка.png`. Авто-разбиение не используем (русский слогораздел нетривиален).
- **Лишние слоги в раунде** берутся из пула слогов всего словаря, а не из случайных букв. В режиме Малыш — 3 лишних, в остальных — 7 (всего 10 карточек снизу).
- **Drag&drop**, не tap. Озвучка слога — в момент начала drag.
- **Ошибка**: попытки 1-2 — мягкий отскок без штрафа, попытка 3+ — отскок + озвучка правильного слога как подсказка.
- **Победа**: конфетти + озвучка слова целиком + автопереход 2-3с.
- **5 режимов сложности** (Малыш / Базовый / Без картинки / На слух / Хардкор) — описаны в PROJECT.md, реализуем все в MVP.
- **Прогресс**: пройденные слова, точность по слогам, звёзды за раунд, экран статистики для родителя.
- **Картинки**: AI-генерация по `image_prompt.md`, единый стиль (flat children illustration, pastel, transparent bg, 1024x1024).
- **Озвучка**: AI-генерация всех файлов оффлайн, складываем в assets. Конкретный сервис (Yandex SpeechKit / ElevenLabs / Google TTS / OpenAI) выбираем перед этапом озвучки.

## Принципы UX (детская аудитория)

- Все интерактивные элементы ≥ 64×64dp (детские пальцы)
- Тёплая пастельная палитра, никаких агрессивных красных
- Слоги на карточках — ВЕРХНИМ РЕГИСТРОМ
- Крупный детский шрифт (Comfortaa / Nunito / Andika)
- Никаких таймеров и штрафов в основном цикле
- Звук сопровождает каждое действие
- Картинка — всегда сверху экрана (палец при drag не перекрывает)

## Принципы кода

- Никаких комментариев в коде (общее правило)
- Не выдумываю поведение — если в PROJECT.md что-то не определено, спрашиваю или предлагаю варианты, не молча решаю
- Перед изменением — проверяю где ещё используется (find_referencing_symbols / grep)
- Слоги храним как value-объекты (`Syllable { text, audioKey }`), а не голые строки — иначе пул слогов и озвучка разъедутся
- Ключи аудио для слогов — латинская транслитерация в lower-case (Ма → `ma`, Ап → `ap`, Бо → `bo`, Ря → `rya`)

## Открытые вопросы (решаем по ходу)

- iOS-сборка — пока не цель, но не закрываем дверь. Не использовать чисто Android-API без альтернативы для iOS.
- Локализация — только русский в MVP. Тексты UI вынести в одно место (легче добавить языки позже).
- Монетизация — пока нет. Без рекламы, без покупок.

## Workflow

1. Любое изменение игровой механики — сначала перечитать `.info/PROJECT.md`
2. Если решение в документации не совпадает с тем, что просит пользователь — обновить документацию явно, не "забыть и сделать по-новому"
3. Перед стартом этапов разработки — план-мод
4. Аудио и картинки готовятся отдельно (вне Flutter), кладутся в `assets/`. Код не должен предполагать наличие конкретных файлов до этапа озвучки/генерации.

## Генерация картинок (правило проекта)

**Все картинки (слова, маскот, фоны и любой графический контент) — генерируются ТОЛЬКО через Gemini Web в браузере через Firefox MCP.** В Firefox уже залогинен мой Google аккаунт — креды на месте, ничего вписывать не надо.

Workflow закодирован в глобальном skill `gemini-image-gen` (`~/.claude/skills/gemini-image-gen/SKILL.md`) — следовать ему дословно. Кратко: открыть https://gemini.google.com/app, включить Temporary chat, заполнить промпт через `fill_by_uid` на внутренний `textbox`, кликнуть Send, polling через `evaluate_script` (НЕ sleep, НЕ take_snapshot), извлечь PNG через canvas+toDataURL, сохранить в нужный путь, прогнать через `tool/remove_bg.py` если нужен прозрачный фон.

**НЕ использовать** для генерации картинок: Pollinations FLUX (`tool/generate_images_pollinations.py`, `tool/generate_mascot_pollinations.py`, `tool/generate_dino_images.py`), Gemini API (`tool/generate_images_gemini.py` — ключ давно невалидный). Эти файлы оставить как историю, но не запускать без явной команды.

Если Firefox MCP недоступен или требует рестарта — не лезть в `~/.claude.json` с конфигом MCP, спросить у пользователя как поступить.
